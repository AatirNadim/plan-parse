Server REST API Architecture

Plan Parse executes as a single Go binary embedding the web dashboard. The server exposes headless REST API endpoints (default: 127.0.0.1:9000) for CI/CD automation, pipeline integration, and plan parsing. These routes are designed for HTTP clients, scripts, and cURL, not direct web browser navigation.

Backend Server Endpoints Reference

HTTP contracts, required parameters, and execution examples for daemon endpoints.

GET /api/health Liveness Probe Path Match
Server health & liveness verification

Returns HTTP 200 with JSON payload confirming the plan-parse server is operational, bound to its socket, and ready to accept requests.

Parameters None
Headers Accept: application/json
Example cURL 
curl -s http://127.0.0.1:9000/api/health
Sample Response (JSON) 
{
  "alive": true
}
Note: Used by container orchestrators, health checks, and CI/CD readiness probes.
GET /api/status CLI Plan State Path Match
Disclose startup CLI plan state & lock status

Reports whether a Terraform plan was loaded at startup via -plan <file> or -dir <path>. Operates with a single-use lifecycle: initial call returns cli_loaded: true, disabled: true; subsequent browser reloads return cli_loaded: false.

Parameters None
Headers Accept: application/json
Example cURL 
curl -s http://127.0.0.1:9000/api/status
Sample Response (JSON) 
{
  "cli_loaded": true,
  "disabled": true
}
Note: Prevents state contamination on UI browser refreshes while preserving initial CLI arguments.
GET /api/graph DAG Payload Path Match
Retrieve pre-parsed dependency graph structure

Fetches the parsed Directed Acyclic Graph (DAG) containing nodes (resources, modules, variables, outputs), edges (dependencies), and change summary statistics.

Parameters None
Headers Accept: application/json
Example cURL 
curl -s http://127.0.0.1:9000/api/graph
Sample Response (JSON) 
{
  "nodes": [
    { "id": "aws_vpc.main", "type": "resource", "action": "create" }
  ],
  "edges": [],
  "summary": { "total": 1, "create": 1, "update": 0, "delete": 0, "replace": 0 }
}
Note: Consumes the startup CLI plan buffer upon retrieval; subsequent requests return an empty graph structure.
POST /api/parse Plan Ingestion Engine Path Match
Ingest & parse Terraform plan JSON without session storage

Parses an uploaded Terraform plan JSON and returns the resolved DAG graph without mutating or retaining server state. Supports raw JSON body or multipart/form-data with field file or plan up to 50MB.

Parameters Raw JSON body OR multipart field 'file' / 'plan'
Headers Content-Type: application/json OR multipart/form-data
Example cURL (Raw JSON) 
curl -X POST http://127.0.0.1:9000/api/parse \
  -H "Content-Type: application/json" \
  --data-binary @tf_plan.json
Example cURL (Multipart Upload) 
curl -X POST http://127.0.0.1:9000/api/parse -F "file=@tf_plan.json"
Note: Fully stateless; enables rapid CI automation without file persistence or session tokens.
